# My Money

A manual-entry, mobile-friendly personal finance tracker. Your financial data stays in your device's browser storage; this repository contains application code only.

## Hosting

Deploy with GitHub Pages by choosing **Settings → Pages → Deploy from a branch → main → /(root)**.

## Privacy

The application runs client-side and does not connect to financial institutions or send transactions to a server. Export a backup from Settings periodically; browser data can be erased.
